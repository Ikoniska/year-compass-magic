# Year Compass Magic

Skapa en applikation för årsplanering (Yearly Planner) med ett modernt, rent och minimalistiskt gränssnitt. Appen ska hjälpa användare att visualisera, sätta och följa sina mål och aktiviteter över ett helt kalenderår.

Följande kärnfunktioner ska ingå:

1. Dashboard (Översikt):

- En visuell årsöversikt uppdelad i 12 månader (kvartalsvis gruppering: Q1, Q2, Q3, Q4).

- En framstegsbar (progress bar) som visar hur stor del av årets totala mål som är avklarade.

- Snabblänkar för att lägga till nya mål eller händelser.

2. Målhantering (Goal Setting):

- Möjlighet att skapa mål inom olika kategorier (t.ex. Arbete, Hälsa, Ekonomi, Personlig utveckling, Relationer) med färgkodning.

- Varje mål ska kunna ha status: "Ej påbörjad", "Inledd", "Halvvägs" och "Slutförd".

- Möjlighet att sätta delmål (milestones) för varje huvudmål.

3. Kalender & Tidslinje:

- En tidslinjevy (Gantt-schema eller månadskort) där man ser större projekt och deadlines utspridda över året.

- Enkel funktion för att flytta fram eller boka om aktiviteter (drag-and-drop-känsla om möjligt).

4. Månads- och Kvartalsreflektion:

- En sektion i slutet av varje månad/kvartal med färdiga frågor för reflektion (t.ex. "Vad gick bra?", "Vad kan förbättras?", "Lärdomar").

Design och UX:

- Använd ett ljust och fräscht tema som standard med möjlighet till Dark Mode.

- Gränssnittet ska kännas som en modern SaaS-produkt (tänk Notion möter Todoist).

- Responsiv design som fungerar lika bra på desktop som på mobilen.

- Lägg till exempeldata (mock data) från start så att appen ser levande ut direkt.
